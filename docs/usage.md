# 手机使用教程

## 首次安装

1. 安装 APK。
2. 首次启动时允许通知权限。
3. 系统弹出 `su` 授权时，选择永久允许。
4. 启动页会自动检测 ROOT、Python 和 OCR 状态。

## 添加账号

1. 进入“账号”页面。
2. 单个添加时输入 `账号` 和 `密码`。
3. 批量导入时粘贴 `账号#密码&账号#密码` 格式文本。

## 启动保活

1. 返回首页。
2. 点击“启动保活”。
3. 前台通知会常驻显示运行状态、下次执行时间、成功/失败账号数和当前进度。

## 定时执行

1. 首页可开启或关闭固定 Cron 规则。
2. 规则固定为 `*/20 * * * *`，即每 20 分钟执行一次。
3. 开启后应用会通过 `AlarmManager + 前台服务 + ROOT 守护` 自动唤醒执行。

## 查看日志

1. 进入“日志”页面可查看实时滚动日志。
2. 支持清空、复制全部和系统分享导出。

## 系统页功能

1. 重新检测 ROOT / Python / OCR 状态
2. 重启保活服务
3. 清理缓存日志
4. 清空账号、配置和缓存
